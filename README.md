## Ghost Toolbox Open

```
Latest, auto-updating, open-sourced Ghost Toolbox for every Windows.
Made by ovsky. Inspired by BATLEZ works.
```

Automatic installation:

1. Start `install.cmd`
2. Be happy :)

Manual installation:

1. Create `Ghost Toolbox` folder in `C:/`
2. Copy repo files to created `Ghost Toolbox` folder
3. Copy `additional/nhcolor.exe` to `Windows/System32`
4. Copy files from `ghost-open-toolbox/additional/runtime` into `Ghost Toolbox` folder or directly into `Windows/System32` directory
5. Run `toolbox.updater.x64.exe` / `update.cmd` / `run.ghost.cmd`
6. Create shortcut for `toolbox.updater.x64.exe` and rename it to `Ghost Toolbox`
7. Now use it always as auto-updating `Ghost Toolbox`!

Yeah!

![Ghost Toolbox Windows Image](https://i.ibb.co/rF4NFWD/windows-ghost-fix.png)

Additional

If you have a system with simplified/cleared Enviroment Variables, you may add these to your Path:

1. Add PowerShell to your ENV PATH: `C:\Windows\System32\WindowsPowerShell\v1.0\`
2. Add reg to your ENV PATH: `C:\Windows\System32\`
3. Add wmic to your ENV PATH: `C:\Windows\System32\wbem\`
